How to install

  1. Gmail: Open this file in a browser, select the rendered preview block with your mouse, copy it, then paste into Settings → General → Signature. Gmail keeps the formatting. Do not paste the HTML source into Gmail. Paste the preview.
  2. Outlook (desktop): Same approach. Copy the rendered preview and paste into File → Options → Mail → Signatures.
  3. Outlook (web) / other clients that accept raw HTML: use the HTML source block.
  4. Set it for both new mail and replies so it appears consistently.
  5. Plain-text mode: use the plain-text version, since some clients strip formatting entirely.
Two things to decide before rolling these out. First, the field-of-study line: recipients outside Texas A&M will not recognize "BMEN" or "ESET" on their own, so both signatures spell the field out with the acronym in parentheses. If you want just the bare acronym, delete the words before it. Second, these signatures deliberately omit a logo image. Image-based signatures are frequently blocked or stripped by corporate mail filters and can trip spam scoring on cold outreach. If you want the ZKK mark in there, host the PNG at a stable URL on the site first, then add it as an <img> in the first table cell.
